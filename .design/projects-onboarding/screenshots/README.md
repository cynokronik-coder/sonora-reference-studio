# Screenshot evidence

The browser-smoke workflow writes the Projects onboarding review captures into this folder during CI.

Required captures:
- `review-projects-empty-mobile-375.png`
- `review-projects-tour-mobile-375.png`
- `review-projects-empty-tablet-768.png`
- `review-projects-tour-tablet-768.png`
- `review-projects-empty-desktop-1280.png`
- `review-projects-tour-desktop-1280.png`

The workflow uploads these files with a 90-day retention period. The authoritative artifact URL and review findings are recorded in `../DESIGN_REVIEW.md` after screenshot inspection.
