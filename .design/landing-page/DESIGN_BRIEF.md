# Design Brief — Sonora Marketing Homepage

**Resource:** `elayadesign/ai-design-skills/skills/landing-page-design/SKILL.md` (MIT)  
**Existing product design source of truth:** `design-system/sonora/MASTER.md`  
**Scope:** Conservative conversion and copy refinement of the existing Sonora marketing homepage, not a full redesign.

## Audience and offer

- **Primary audience:** independent artists and producers who want to improve a mix with reference tracks while keeping control of the processing decisions.
- **Secondary audience:** engineers who want measured analysis and configurable DSP.
- **Offer:** a browser-based mixing and mastering workspace with reference matching, local audio analysis, editable DSP, offline rendering and optional connected AI guidance.
- **Primary conversion:** open the Sonora Studio.
- **Secondary action:** jump to the four-step workflow.
- **Risk reversal:** the Free plan includes local audio tools, analysis and exports; no payment is required.

## Evidence-backed proof

- 16 built-in DSP processor types are registered in the current audio engine.
- The spectrum analysis uses 31 frequency bands.
- Audio analysis runs locally in the browser.
- Processor proposals require explicit user approval.
- The Free plan includes local DSP, analysis, Reference Match, offline rendering and export.
- The connected assistant receives project metadata and measured results, not raw PCM audio.

No testimonials, customer logos, user counts, performance percentages, guarantees, or unsupported AI claims are available; none are added.

## Primary objections to answer

1. Does reference matching copy the reference? No; it compares measurable characteristics and suggests editable changes.
2. Does the assistant receive raw audio? No; the connected assistant receives project context and computed measurements.
3. Can suggestions be changed or rejected? Yes; processor proposals are previewed and require approval.
4. Do I need to be an engineer? No; Beginner mode is available, with Engineer mode for deeper controls.
5. What can I export? WAV, AIFF and MP3.
6. Is Sonora a full DAW replacement? No; it is a focused production, reference-matching and mastering workspace.

## Page outline

1. Hero: clear reference-matching benefit, audience, one primary CTA, one secondary anchor, Free-plan reassurance.
2. Proof strip: local analysis, 16 built-in processors, user approval.
3. Brand/tagline moment: the existing “A result matters…” statement with a restrained word reveal.
4. Five capability cards: combine analysis and reference matching; keep multitrack, DSP, rendering and optional AI distinct.
5. Four real workflow steps: preserve the product's actual process.
6. Audience context: artists, producers and engineers.
7. Six FAQs: answer the primary objections.
8. Final CTA and footer.

## Design constraints

- Preserve Sonora's dark studio visual language, existing Inter and JetBrains Mono typography, accent colors, shared components, spacing and motion tokens.
- Do not copy the upstream skill's default Geist/neutral visual system over Sonora's established design system.
- Keep the hero CTA as “Open the studio”; do not invent a trial, guarantee, customer proof or pricing claim.
- Keep the existing product preview explicitly labelled as illustrative.
- No new dependencies or global environment changes.
- The upstream skill recommends a companion redesign skill for existing websites; that companion is outside the 19-resource sequence. This pass therefore applies compatible landing-page strategy and copy guidance without a wholesale redesign.

The repository has title, description and Open Graph title/description metadata. There is no approved social-share image, canonical production domain, privacy policy or terms page in the current project; no image, URL or legal copy is invented.
